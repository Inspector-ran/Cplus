# 04 指针与引用

[返回项目首页](../README.md) · [完整使用指南](../USAGE.md) · [配套练习](../06-exercises/README.md)

## 学习目标

能区分地址、指针、解引用和引用，理解通过参数修改外部数据。

## 核心概念

- `&value` 取地址，`int* pointer` 声明指针，`*pointer` 访问所指对象。
- 指针必须指向仍然有效的对象后才能解引用；空指针使用 `nullptr` 表示，不能解引用。
- 指针参数本身仍是按值传递，通过它访问的对象可以被修改。
- C++ 的 `int& alias = value;` 为已有变量建立引用；引用声明时需要绑定对象。
- `void change(int& value)` 是引用参数，调用时传变量本身；指针参数则通常传地址。
- 本例要求两个地址都有效且可写，不处理动态分配；不需要 new/delete。

## 示例说明

[swap.cpp](swap.cpp)：使用指针交换两个变量，打印前后状态。示例使用固定数据，不需要键盘输入；每次只编译本文件。

预期输出：

```text
Before: 3, 7
After: 7, 3
```

## 常见错误

- 解引用未初始化指针或 nullptr。
- 交换了指针自身，却没有修改两个整数。
- 没有临时变量，丢失原值。
- 混淆定义引用时的 & 和表达式中取地址的 &。
