# 06 C++ 配套练习

[返回项目首页](../README.md) · [完整使用指南](../USAGE.md)

每题单独建立一个 `.cpp` 文件，保存到本目录，分别编译运行。初始不放答案；先独立实现，再做边界测试。

以下 01～05 题的输入使用 `std::cin`，输出使用 `std::cout`；不要额外打印输入提示语。检查读取结果与题目范围，非法输入返回非零退出码，无需规定错误消息。本套题使用普通数字文本，不要求额外编写任意精度解析器。

## 01 基础语法：统计正数、负数和零

文件名：`01-count-signs.cpp`。

输入五个整数，每个数范围 -1000～1000。使用循环与分支统计正数、负数和零的个数，按此顺序输出，用空格分隔。

输入：

```text
-2 0 3 5 -1
```

输出：

```text
2 2 1
```

边界：五个 0 输出 `0 0 5`；全为正数输出 `5 0 0`；全为负数输出 `0 5 0`。检查是否成功读满五个数。

## 02 数组：最小值与最大值

文件名：`02-array-min-max.cpp`。

先输入 n（1～20），再输入 n 个整数（每个 -1000～1000）。先保存到固定容量数组，随后遍历求最小值和最大值，按此顺序输出。

输入：

```text
5
4 1 9 3 7
```

输出：

```text
1 9
```

边界：只有 -3 时输出 `-3 -3`；{-4, -1, -9} 输出 `-9 -1`；相同元素的最小值与最大值相等。使用前 n 个有效元素，不读取数组剩余位置。

## 03 函数：判断素数

文件名：`03-is-prime.cpp`。

输入一个整数 n（0～10000）。实现并调用 `bool is_prime(int n)`。是素数输出 `YES`，否则输出 `NO`。

输入：

```text
17
```

输出：

```text
YES
```

边界：0、1 输出 NO；2 输出 YES；9、25、10000 输出 NO。先处理小于 2 的情况，保证循环边界不会漏掉完全平方数的因数。

## 04 指针：数组元素加一

文件名：`04-increment-array.cpp`。

先输入 n（1～20），再输入 n 个整数（每个 -100～100）。实现 `void increment_all(int* values, int count)`，通过指针访问并原地将每个元素加一。输出修改后的数组，用单个空格分隔，无末尾空格，最后换行。

输入：

```text
3
-1 0 5
```

输出：

```text
0 1 6
```

边界：单元素 100 变为 101；重复元素分别加一。函数只访问前 count 个元素；count 为 0 时不访问内存。count 大于 0 时调用者必须提供有效数组地址。

## 05 结构体：寻找最高分学生

文件名：`05-top-student.cpp`。

用包含 `std::string name` 和 `int score` 的结构体数组保存学生。先输入学生数 n（1～10），随后每行输入姓名与成绩。姓名为 1～19 个 ASCII 英文字母、无空格；成绩为 0～100 的整数。

输出最高分学生的姓名与成绩。并列时保留输入顺序最早的一名。

输入：

```text
3
Lin 90
Chen 95
Wu 95
```

输出：

```text
Chen 95
```

边界：一名学生时直接输出该生；0 分、100 分均有效；并列应保留首名。使用 std::string 接收姓名，检查长度、字母范围及读取结果；不要把字符串输入当成数值输入处理。
