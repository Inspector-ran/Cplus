## 学习目标

能使用变量、分支、循环和标准输入输出，知道 C++ 源文件如何编译。

## 核心概念

- 程序入口使用 `int main()`，源文件后缀为 `.cpp`。
- `int`、`double`、`char`、`bool` 分别表示整数、浮点数、字符和布尔值；使用前初始化。
- `const` 对象不能重新赋值；`=` 是赋值，`==` 是比较。
- `std::cout << value` 输出，`std::cin >> value` 输入；`if (!(std::cin >> value))` 可检测读取失败。
- `std::` 指明名称来自标准命名空间。示例保留它，以便分辨标准库名称与自己的变量。
- 整数相除舍去小数部分；`%` 求余；`if/else` 选择分支，`for/while` 控制重复执行。
- 本项目使用 C++17 模式，但起步示例只用基础特性。

## 示例说明

[variables_and_loops.cpp](variables_and_loops.cpp)：累加 1 到 5，通过 std::cout 输出。示例使用固定数据，不需要键盘输入；每次只编译本文件。

预期输出：

```text
15
```

## 常见错误

- 混淆赋值和比较；累加器未初始化；循环边界漏算或多算。
- 以为整数除法会自动得到小数。
- 输入读取失败后继续计算；忘记包含 `<iostream>` 或写 std::。
