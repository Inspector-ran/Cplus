# 02 数组

[返回项目首页](../README.md) · [完整使用指南](../USAGE.md) · [配套练习](../06-exercises/README.md)

## 学习目标

能遍历固定长度数组，正确初始化最大值，处理下标与长度。

## 核心概念

- `int values[20]{};` 定义并零初始化固定容量数组。
- 有 n 个元素时，下标从 0 到 n - 1。
- 本例用首元素初始化最大值，避免全负数时错误地得到 0。
- 在数组定义所在作用域，可用 `sizeof numbers / sizeof numbers[0]` 求长度。
- 数组作为普通函数参数会转换成指针，长度需要单独传入。
- 标准 C++ 不支持以运行时变量 n 声明 `int values[n];`；本阶段使用固定容量和有效长度。以后再学习 `std::array` 与 `std::vector`。

## 示例说明

[array_max.cpp](array_max.cpp)：在五个整数中寻找最大值。示例使用固定数据，不需要键盘输入；每次只编译本文件。

预期输出：

```text

```

## 常见错误

- 使用 <= count 导致越界。
- 将最大值初始化为 0，导致全负数情况错误。
- 混淆容量与已输入的有效元素数量。
- 使用部分编译器支持但标准 C++ 不支持的变长数组。
