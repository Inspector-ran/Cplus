# 05 结构体

[返回项目首页](../README.md) · [完整使用指南](../USAGE.md) · [配套练习](../06-exercises/README.md)

## 学习目标

能组织相关信息，使用 std::string 成员，并通过只读引用传递结构体。

## 核心概念

- `struct Student` 定义类型后，在 C++ 中可以直接用 `Student` 声明对象。
- `std::string` 来自 `<string>`，用于保存文本；与 C 的字符数组用法不同。
- 普通对象使用点号访问成员，结构体指针使用箭头。
- `const Student&` 是只读引用，传参时不复制整个 Student，函数不能通过它修改对象。
- `std::fixed << std::setprecision(1)` 配合使用，按小数点后一位输出。
- 先掌握数据组织；类、构造函数和访问控制可作为后续单独主题。

## 示例说明

[student.cpp](student.cpp)：创建学生对象，通过只读引用交给打印函数。示例使用固定数据，不需要键盘输入；每次只编译本文件。

预期输出：

```text
Name: Chen
Age: 19
Score: 88.5
```

## 常见错误

- 忘记结构体定义末尾的分号。
- 混淆对象的 . 和指针的 ->。
- 以为 C++ 的 std::string 用法可以原样用于 C。
- 只写 setprecision(1) 而没有 fixed，误以为始终表示小数点后一位。
