# 03 函数

[返回项目首页](../README.md) · [完整使用指南](../USAGE.md) · [配套练习](../06-exercises/README.md)

## 学习目标

理解声明、定义、返回值与参数传值，并认识函数重载。

## 核心概念

- 调用前必须有可见的函数声明或定义。
- 普通参数按值传递；修改形参不改变调用者的变量。
- C++ 支持函数重载：同名函数可以有不同的参数列表。
- 本例分别提供 int 参数和 double 参数的版本；不能只依靠返回类型区分重载。
- `condition ? first : second` 根据条件选择结果，等价于简单的 if/else 返回逻辑。
- 引用参数将在指针说明中对照介绍，结构体示例会用到只读引用。

## 示例说明

[overloaded_max.cpp](overloaded_max.cpp)：分别调用整数和浮点数的同名函数。示例使用固定数据，不需要键盘输入；每次只编译本文件。

预期输出：

```text
Int max: 7
Double max: 3.5
```

## 常见错误

- 以为只改变返回类型就能重载。
- 声明与定义的参数不一致。
- 非 void 函数遗漏返回值。
- 对本例传入 (3, 7.5) 这样的混合类型，可能产生重载歧义；先明确希望调用哪个版本，并使用一致的类型。
